# plsig

**pl**ease be **sig**nificant: free in-browser statistics and scientific graphing in the spirit of GraphPad Prism. Everything is in one file, `index.html`, with no build step; `sw.js` beside it is the offline service worker (network-first for the page, cache-first for the two pinned jsDelivr scripts; bump `CACHE` when its logic changes). The only scripts it loads are jStat and the Plotly cartesian bundle, from jsDelivr with SRI hashes. Live at https://jieqianghe.github.io/plsig/ (GitHub Pages, served from `main`).

The project was called ministat until Nov 2026, when the repository was renamed. Sessions and the theme that the browser saved under the old `ministat:` localStorage keys are still read on load; keep that fallback.

## Workflow

- When a change is done: commit, push the working branch, open a PR into `main`, and merge it. This is the user's standing instruction (Nov 2026).
- If the working branch's PR has already been merged, restart the branch from `origin/main` before new work. Don't stack new commits on merged history.

## Interface: the user's choices

- No logo and no app name anywhere in the interface. The only place the name appears is the tab title, `plsig — please be significant`.
- The colours follow the user's svguest project. Since the RStudio-style redesign (Nov 2026) bar buttons are flat with 3px radii and show a fill on hover; menu buttons (test, post-hoc, theme, W / H) keep a soft fill (`--seg-bg`). The interface colours follow svguest (user's choice, Nov 2026, replacing the warm Claude palette, which they found too much): light mode is plain white / light grey (`#ffffff`, `#f7f7f7`, `#f2f2f2`), ink `#262626`, blue accent `#1a73e8`; dark mode is neutral grey (`#1f1f1f`, `#262626`, `#303030`), text `#e3e3e3`, accent `#4c8df6`. The figure itself is always drawn on white paper, flat, with a hairline edge only; the user found a drop shadow looked embossed. The active sheet tab has no coloured line.
- Font: Arial everywhere, in the interface and in the figures (user's choice, Nov 2026). Chinese text falls back to PingFang SC / Microsoft YaHei.
- Figure style (user's choice, Nov 2026): outside tick marks on both axes, one per value tick and one per sample; no gridlines inside the plot; data points take their group's colour, and error bars / mean lines take a darker tone of it. The default colour theme is `claude`: Anthropic's brand orange `#d97757`, blue `#6a9bcc`, green `#788c5d` and warm grey `#b0aea5`, then tones of the same family. The other themes are Classic Prism (the user dropped Pastel and Vibrant, Nov 2026; a saved session that used one of those opens in Claude) and seven journal-style palettes taken verbatim from ggsci 5.2.0 (NPG, AAAS, NEJM, Lancet, JAMA, JCO, D3; GPL ≥ 3, compatible with plsig's GPL-3; credited in the code, the menu hint and Help). To add a theme, add one entry (with a `name`) to `THEMES`: the Graph group's colour menu is built from it.
- Layout (Nov 2026; the user wants "a professional statistics program", not a copy of svguest, and found earlier rounds rough and badly arranged). Rule: each pane owns its tools.
  - menu bar (`#menubar`, built from `MENUS`: "File ▾" titles, borderless 8px drop-downs, ✓ on the current choice (`on`), a tip per item (`tip`, needs a `ZH` entry); every item runs an existing button by id or a small function). Theme, language, help and GitHub exist only in the menus (their buttons sit in a hidden div in `#ribbon`);
  - top bar (`#ribbon`, 40px): app-level commands only: Open, Save | undo, redo | Paste | test + option + Run | Share (right);
  - data pane (`#vData`): sheet tabs (`#tabs`), a tool strip (`#dataTools.pane-tools`: Subcolumns, Transform | +Row, +Col | Analyze selection … copy, clear), the scope bar (`#scopeBar`, only when a scope or a grouping column is active), the sheet, the paste bar + Examples;
  - plot pane (`#graphPane`): header (`#graphHead`: W, H, Reset, Copy, Export), tool strip (`#graphTools`: chart type, error bars, colour theme, significance … Style), the figure, and the hint as a one-line footer (`#plotHint`);
  - results pane (`#resPane`): a Results / Figure style switch (`#resTabs`, the same segment tray as elsewhere; the user found a bordered Results chip with a chevron ugly), Copy table, and a fold arrow (`#foldBtn`) at the right; split from the plot by `#splitV` (`plsig:splitV`). Figure style stays here, under the figure, on purpose: the figure must stay in view while it is styled (the user's earlier request), and the Style button in the plot's tool strip opens the same card. The verdict is a plain green box (no left bar: the user's choice); grey when not significant.
  - one control system: 26px controls, 6px corners, segments in a tray with a raised chip, 16px hairline separators, panes 8px on the bar grey. Rules for bars use `:is(#ribbon, #graphHead, #graphTools, #dataTools)`. Results are a white report page with rule-style tables (heavy top rule, thin header and bottom rules) and the verdict as a left-bar callout. The last blocks of `<style>` (v3) win over the older layers.
- No status bar (removed Nov 2026). Theme (View → Dark / Light interface), language (View → 中文 / English), Help and the GitHub link (Help menu) live only in the menus (user's request, Nov 2026); the tips and the "runs locally" note live in the Help dialog.
- Short options are segmented controls; the real `<select>` behind each stays hidden and holds the value.
- Toolbar in svguest's style (user's request, Nov 2026; tokens copied from svguest app.html: `--sv-btn`, `--sv-btnb`, `--sv-btnh`, `--sv-sh`, `--sv-h4`): the menu bar and toolbar are svguest's `--bar` grey (#e9e9e9 / #1f1f1f); buttons are transparent with 6–7px corners, muted icons and a translucent hover; the chosen segment is a raised chip; menu buttons (test, post-hoc, theme, W / H) read as fields; groups are split by 18px hairlines; 26px controls, no captions. The Plot pane header (`#graphHead`) uses the same rules. Chart type is a segment of small chart glyphs (`SEG_ICONS` / `segContent`); the colour theme is a menu button showing the theme's swatch, and its list shows each theme's whole palette. The Sheet group puts undo / redo / clear on one row of icons and +Row / +Col below. Results re-run on every edit, so Run is a small button beside the test.
- Everything in the ribbon is a button (user's choice, Nov 2026). The test, post-hoc and Dunn choices are flat menu buttons (`select.as-menu`): they open a grouped list in `#menuPop` with a hint per item (`data-hint`), and the hidden `<select>` holds the value. Welch's correction is an on / off button over a hidden checkbox. Text on the figure is edited where it stands (`textTargets` / `openTextEditor`): an axis title, a group name under the x axis or a legend entry; group names and legend entries rename the sheet's column or row title as one undo step, and legend clicks no longer hide series (`itemclick: false`). Axis titles are not in the ribbon: you click one on the figure to rename it, and the hidden `xLabel` / `yLabel` inputs store the result. The editor is our own `<input>` laid over the title (`openTitleEditor`), not Plotly's `edits.axisTitleText`, which lost the text in the user's browser (Nov 2026); it ignores Enter during IME composition. An empty title is drawn as a faint placeholder on screen (`placeholderAxes`) and left out of PNG / SVG exports. A faint line under the figure says so (`#plotHint`). W / H / Dot are buttons too (`SIZE_BTNS`): each opens a stepper (− / +) with presets in `#menuPop`, and a hidden number input holds the value. The W / H popover (`#menuPop.sz-pop`) is symmetric: centred title, the pill stepper, Auto across the full width, then the presets as a three-column grid of equal chips. W / H blank = automatic: `sizeFor(spec)` picks a size from the number of bars, label length and legend, and shows it in muted text; a chosen value overrides it, Reset goes back to automatic.
- Style button (Plot pane header) or the Style tab opens a card, `#styleCard`, in the bottom pane in the results' place (user's request, Nov 2026: the floating panel covered the figure). Style and results take turns, never both: `#vOut.styling` hides `#vResults`, the figure keeps its full height and the card scrolls in what is left; × / Escape / the Style button close it and the results come back. Clicks on the figure leave it open; `refreshStyleCard` (in `syncSegs`) shows settings changed elsewhere. The Style button has no chevron (it opens a card, not a menu). Font and dots share one row; every stepper value (Font, Dots, and W / H in `#menuPop`) is a number field you can type in (`.st-val`, clamped to the step's min / max on Enter or blur; ↑ / ↓ step it). The card has font size (all figure fonts scale with it, 13 = default), dot size, bar width (Narrow / Normal / Wide), points (Filled / Hollow / Hidden; data-point traces carry `meta: "pts"`) and frame (Box, or Axes = left and bottom only, as in many papers). Hidden fields `fontSize` / `barWidth` / `pointStyle` / `frame` hold the values; `applyStyle` runs in `render`. The same panel has a Y axis section: scale (linear / log; annotations move to log10 units), range, a dashed reference line and a shaded band (`yScale`, `yMin`, `yMax`, `refY`, `bandLo`, `bandHi`).
- Broken y axis (Style → Y axis → Break from … to …; `breakLo` / `breakHi`): `applyBreak` (last step of `render`) stacks two y axes (`yaxis` = bottom … from, `yaxis2` = to … top), duplicates every trace onto y2, moves annotations / shapes to the part they fall in (letters keep their gap above the bar via `_base`; marks in the gap go just under it), and draws // marks on the axis lines. Off on a log axis or when the gap is outside the range.
- The style card is two columns where the pane is wide enough (one below about 520px). Left: font, dots, bars, points, frame, error bars (Both / Up: `errDir`), journal preset (`journal`: Nature / Cell / Science / PNAS = 7 pt text and 0.75 pt lines at the journal's single-column width, computed live from the figure width in `applyStyle`; Export's "As shown" then uses the journal width), my default. Right: Y axis, Significance: marks (Letters / Brackets, `sigMarks`) and which comparisons show (`sigShow`: Auto / Significant / All / Vs first / Pick; picks are a JSON list in `sigPick`, keyed "A vs B" or "Row: A vs B"). Brackets are placed by `placeBrackets`; letter-mode specs carry `pairs`.
- Transform (button at the right of the tab strip; per sheet): `transformGroups` runs before every analysis: % of first column, log10 / ln (values ≤ 0 left out), average replicates (rows sharing a row title). Off for chisq / corr; averaging off for twoway / cells. The y title default and the methods paragraph follow it (`yDefault`, `lastTransform`).
- My default (Style → Save as my default): `MY_STYLE_IDS` saved in `plsig:mystyle`; `graphDefaults()` (= GRAPH_DEFAULTS + it) drives Reset, new visits and Examples.
- Clicking the figure (user's request, Nov 2026): a bar click selects it (Shift / ⌘ / Ctrl adds; dotted `selbox` outline, screen-only, stripped from exports) and opens the format bar `#fmtBar` (colour); a text click opens the text box plus bold / italic / size / colour (y-axis numbers and significance marks are format-only). Formatting lives in the per-sheet setting `figFmt` (JSON: `bar` colours by series name; `text` by key `xtitle` / `ytitle` / `xt:<label>` / `lg:<entry>` / `yticks` / `sig`), applied with Plotly pseudo-HTML (`styled`) or font objects (`fontFmt`); renaming from the figure moves the keys (`moveFmtKeys`). Right-click the figure (`#plot` contextmenu): compare the selected bars in a new tab (raw sheet data, `compareInNewTab`: t / Mann–Whitney / paired for two, ANOVA / Kruskal–Wallis for three or more), show only / hide them (column `off`), copy as SVG / PNG. Plotly's click fires for the right button too: ignore `button === 2`. Copy (ribbon) is a menu, PNG or SVG; the SVG goes on the clipboard as text/plain + text/html (+ image/svg+xml where allowed), which svguest's paste reads. The hint under the figure points to svguest (https://www.svguest.online).
- The right-click menu (`#ctxMenu`, sheet, tabs and figure) and the figure's format bar (`#fmtBar`) follow svguest (user's request, Nov 2026; its `.menu` / `#mCM` / `.win` / `#mFS`): menus (also `#mbPop`, `#menuPop`) in `--sv-btn` with no border, 8px corners and `--sv-shm`, items indented 22px, translucent hover; the format bar a floating window in `--sv-side` with 10px corners, svguest default buttons (`on` = `--sv-on`), swatches with 3px corners and the `--sv-swb` hairline.
- Results fold (user's request, Nov 2026): shown by default; the fold arrow (`#foldBtn`) folds every table away and keeps the verdict (`plsig:resFolded`); folded, the bottom pane shrinks to its header and the verdict and the Plot pane takes the rest (`#vOut.res-folded`); each section title folds that table (`shutSections`, by English title, in `plsig:shut`), kept across re-runs.
- Results and the Style card follow svguest's side panel (user's request, Nov 2026): the pane body in `--sv-side`; report sections split by `--sv-h4b` hairlines with a 12px heading and the fold chevron at the right; tables without a header fill; the verdict and methods as `--sv-btn` cards; in the card, labels in `--sv-h4`, fields like svguest's `.f`, segments as svguest's `.seg` tray with a raised chip, plain buttons as svguest's default button. `#menuPop` lists hover with the translucent `--sv-btnh`, not the accent.
- Methods paragraph: `methodsText(test, groups, plot)` writes a "Statistical analysis" paragraph (English or Chinese, following the interface) into `report.methods`, shown under the results with its own Copy button. When a test's behaviour changes, update its sentence there.
- Significance segment: *** / P = / Off. Off hides every figure mark tagged `name: "sig"` (letters, stars, brackets, the XY stats box); the results stay.
- Export (Size & export group) opens `#menuPop`: content (this figure / all sheets as a panel figure lettered A, B, C…), PNG / SVG, width (as shown / 8.5 / 11.4 / 17.4 cm), DPI 300 / 600, columns. Panels keep their own size and the page scales uniformly, so fonts match across panels; `withDpi` writes a pHYs chunk. All-sheets export shows each tab in turn (`allFigures`) and comes back. Copy puts a 300 dpi PNG on the clipboard. Choices persist in `plsig:export`.
- Legends (grouped, contingency) sit in their own band at the foot of the figure (`bottomLegend`), under the x title. Axes use `automargin`, so rotated tick labels push the title down. Natural width is about 1130px.
- Examples (the button at the right of the paste bar) opens a gallery, `EXAMPLES`, with one data set per kind of test laid out as that test reads it; each opens in a new tab (a blank current tab is reused).
- Help, the tour and the popovers follow svguest too (user's request, Nov 2026; its `#mHelp`, `.win`, `.pri`): the help dialog has a search box in its header (`#helpQ`, filters the cards in both languages) and its topics as a left column; each card is a hairline row (term | text); the tour box is a floating window whose Next / Done is svguest's dark primary button, as is Export's Download. - Help dialog (Nov 2026 redesign): a quick-start strip of three numbered steps, section chips (they scroll inside the dialog with JS: never set the address hash, which carries `#s=` share links), then seven sections (The window, Your data, The sheet, The figure, Results, Files and sharing, About), each a grid of cards (`.hi`, a `<dt>` + `<dd>` in a `<div>`). - Interface language (Nov 2026): View → 中文 / English (hidden `#langBtn`) (`setLang`, saved in `plsig:lang`; the first visit follows the browser's language). - Tier-3 features (Nov 2026): Share (right of the tabs) puts every tab, gzipped + base64url, after `#s=` in the address (`shareLink` / `readShareHash`; a first visit replaces the demo sheet, the shared active tab opens). ## Code map (inside `index.html`)

- `Stats`: pure statistics functions with no DOM access.
- `ANALYSES[test](groups, problems)`: each returns `{ verdict, report, plot }`. `cells` (One-way ANOVA across grouped cells) treats every row-title × column cell as a group, reuses `ANALYSES.anova`, and draws clusters with letters per bar; cells may be empty (a Control row with one column), as in clustered paper figures. The report model drives both the on-screen tables and the copied TSV.
- Curves (Nov 2026): `dose` fits a 4PL (`S.fit4pl`, Levenberg–Marquardt on log10 dose, SEs from s²(JᵀJ)⁻¹, checked against scipy curve_fit); `survival` uses `S.kaplanMeier` + `S.logRank` (checked against scipy.stats.ecdf / logrank). Layouts: column A = dose or time, other columns = replicate responses, or 1 event / 0 censored per group.
- Outliers: `flagOutliers` runs `S.grubbs` (two-sided, α = 0.05, repeated; checked against the NIST handbook example) on each analysed column, highlights cells (`td.flag`) and lists them; nothing is removed. Single values are excluded by right-click → Exclude value: rows kept in `grid[g].xr` (shifted by insert / delete row), shown struck through, skipped by `collectGroups`; the methods paragraph counts them.
- `drawPlot(spec)`: dispatches on `spec.mode`. Column plots use `two` / `letters` / `control` / `each` / `none`; the other modes are `xy`, `counts`, `grouped`, `dose` and `surv`.
- Data model:
  - `grid`: an array of columns, each `{ name, cells }`;
  - `titles`: the row titles, which name the row-factor levels for two-way ANOVA and the outcomes of contingency tables.

  Both are kept in undo, in localStorage and in `.jgz` files.
- Sheet tabs (Nov 2026): `sheets` holds one entry per tab, `{ name, grid, titles, settings }`; the active one lives in the usual globals and the ribbon, and `showSheet` / `stashSheet` swap them (each tab keeps its own undo stacks). localStorage and `.jgz` v5 store `sheets` + `cur` next to the old top-level `grid` / `titles` / `settings`, so older files and older code still read. Open appends a file's sheets as new tabs (a blank current tab is replaced). A column with `off: true` is excluded from the analysis (right-click → Exclude / Include): it stays on the sheet, greyed and struck through, and `collectGroups` drops it.
- The sheet behaves like Excel (user's request, Nov 2026): `sel` holds the active cell and the far corner of a range; a click selects a cell (typing replaces it), double-click or F2 edits inside it; drag / Shift selects blocks for copy, cut, paste, Delete and fill-down; right-click opens insert / delete for rows and columns (and move columns left / right); a dotted handle at the left of a column name drags the column to a new place (HTML5 drag, `moveColumn`), and the figure's order follows; clicking the empty grid grows the sheet. The sheet owns ⌘/Ctrl+Z, because a cell input always holds focus. Results re-run by themselves after every edit (`scheduleRun`).
- Subcolumns (Nov 2026, user's request, after Prism's grouped table): the per-sheet setting `subcols` (1–6, button left of Transform, `setSubcols`) makes every N consecutive grid columns one data set: a spanning data-set header row (`tr.set-row`, name on the first column, `normalizeSets` copies it to the others) over `A:1, A:2 …` labels. Header cells carry `data-g` / `data-g1`; use `headRow()` / `thSpan()`, never `tHead.rows[0]` or `cellIndex`. Column insert / delete / move and drag work in whole sets (`setRange`). `mergeSubcols` (in `run`, before `transformGroups`) pools each set's subcolumns into one group, keeping rows, so two-way ANOVA / cells see N replicates per row × set; matched-row tests average per row; XY, survival and counts read the columns as they are. A pasted header naming each set once over blank cells sets N (`subcolsInHeader`). The table has an explicit pixel width, so its columns never squeeze when the splitter narrows the pane (that misaligned the gridline background).
- Pick what to analyse (Nov 2026, user's idea: "put all the data in, then choose"): `pick: true` on columns is the scope (Analyze selection / right-click → Analyze only…, `analyzeSelection`, `clearScope`); when any column is picked, `collectGroups` reads only picked ones and the rest are dimmed. Rows too (user's request): a block or whole-row selection also sets `pr`, the list of rows in scope, kept identically on every column (so it travels with undo, files and row inserts / deletes like `xr`); `rowScope()` reads it, `anyScope()` = columns or rows; a single cell or whole columns scope columns only; a grouping column left with one label inside the scoped rows is ignored. Grouping columns (long format): `isFactorCol` = a column of repeated text labels, or `fac: true` set by right-click (`fac: false` forces values); `reshapeLong` (in `run`, after `mergeSubcols`) turns labels + a value column into groups (one factor → groups per label; two → row level × columns for two-way / cells, or every combination for one-way tests; one factor + several value columns → labels act as row titles). `longInfo` says where labels live; analyses read row levels through `rowTitle(r)`, never `titles[r]`. A test that cannot read the shape is switched (`suggestTests`); `#scopeBar` shows what is analysed and chips for the tests that fit (`shapeTests`, `SHORT_TEST`). `paintColumnRoles` marks roles on the sheet. Settings changed inside `mutate` belong to that undo step (`settingsSettled` there). Long two-way was checked against the wide layout of the same data: identical table.
- Under the sheet is a paste bar (user's request, Nov 2026), not a textarea: click it (or Paste in the ribbon) and press ⌘/Ctrl+V, and the clipboard replaces the sheet as one undo step. A visually hidden `#pasteCatch` textarea takes the focus so the paste event fires in every browser. `importClipboard` reads tab-separated text (Excel, Sheets, Word) first, then the first HTML `<table>` (web pages), then `parseDelimited`, which also splits space-separated text from PDFs. Dropping a .csv / .txt file on the bar works too.
