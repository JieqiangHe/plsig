Tips

Layout
One column per group. Paired, repeated-measures and Friedman tests match values by row (one subject per row). Correlation uses column A as X and B as Y. Contingency tables hold counts: columns are groups, rows are outcomes (named by the row titles).
Two-way
Columns are the levels of one factor (e.g. Control / Drug); the row title names the level of the other (e.g. Male / Female). Put each replicate on its own row and repeat the row title.
Clusters
For bars in clusters with letters over each bar (e.g. Control, P1–P3 × M1–M3), choose One-way ANOVA across grouped cells. The row title names the cluster on the x axis and each column is a bar colour; every row-title × column cell is one group, and cells may stay empty (a Control row fills only its own column).
Exclude
Right-click a column (or a block of columns) and choose Exclude from the analysis to keep the data on the sheet but out of the test and the figure. The same menu includes it again.
Sheets
The tabs over the sheet each hold their own data, test, figure options and undo history: one tab per figure. + (or a double-click on the empty strip) adds one; double-click a tab to rename it; right-click to duplicate, move or delete. Save writes every tab into one .jgz file, and Open adds a file's tabs to the ones you have.
Paste
Paste a block from Excel/Sheets into any cell (⌘/Ctrl V); the grid expands to fit. To replace the whole sheet, click the paste bar under the sheet (or Paste in the ribbon) and press ⌘/Ctrl V: tables from Excel, Word, web pages, PDFs and CSV text all work, with or without a header row. You can also drop a .csv / .txt file on the bar.
Select
Click a cell and just type to replace it; double-click or F2 to edit inside it. Drag, or Shift + click / arrows, to select a block; click a row number or column letter for a whole row or column; ⌘/Ctrl A selects everything. Click the empty grid to add rows and columns there.
Move
Arrows, Tab and Enter move between cells (Enter on the last row adds one); ⌘/Ctrl + arrow jumps to the edge.
Edit
Copy, cut and paste work on blocks; one copied value pasted onto a block fills it. Delete clears the block, ⌘/Ctrl D fills down, Esc cancels a change. Type a value with a block selected and press ⌘/Ctrl Enter to put it in every cell. Right-click for insert / delete rows and columns. Drag a column by the dotted handle at the left of its name (or right-click → Move left / right) to reorder it; the figure follows. Results update as you type.
Undo
⌘/Ctrl Z; add Shift for redo. Undo covers the data and the figure settings (chart, colours, size, style, test).
Session
Saved in this browser automatically; Save / Open (.jgz) moves a session between machines.
Format
Click a bar to pick its colour, or any text (titles, group names, legend, letters / stars, y-axis numbers) for bold, italic, colour and size. Shift-click bars to select several; right-click the figure to compare the selected bars in a new tab (t-test, Mann–Whitney, ANOVA, Kruskal–Wallis), show or hide them, or copy the figure as SVG or PNG. For finer editing, paste the SVG into svguest.
Figure text
Click any text on the figure to edit it: an axis title, a group name under the x axis, or a legend entry. Group names and legend entries rename the column or row title on the sheet (⌘/Ctrl Z undoes it). Enter keeps the change, Esc cancels. A cleared axis title stays as a faint placeholder on screen so you can click it again; exports leave it out. Off next to *** / P = hides the letters and stars on the figure.
Y axis
Style → Y axis: linear or log scale, a fixed range (blank = automatic), a dashed reference line at a value, and a shaded band between two values.
Style
Style in the ribbon sets the figure's font size, dot size, bar width, hollow or hidden points, and a box or open (left and bottom axes) frame.
My style
Style → Save as my default keeps the chart type, error bars, colours, significance labels and style in this browser: Reset, new visits and Examples then use it. Forget it returns to the built-in defaults.
Results
Click Results to fold the tables away (the one-line conclusion stays), or click one table's title to fold just that table. Folds are remembered.
Methods
Under the results, a ready-to-copy paragraph for a paper's methods section describes the test that ran, its post-hoc test, how the data are shown and the sample size.
Curves
Dose–response curve (4PL): column A = dose, the other columns = replicate responses; a four-parameter logistic is fitted on log10(dose) and reports EC50 / IC50 with its 95% CI. Kaplan–Meier survival: column A = time, each other column a group with 1 = event and 0 = censored (blank = not in that group); curves are compared with the log-rank test.
Outliers
Grubbs' test (α = 0.05) runs on every column; suspected outliers are highlighted on the sheet and listed in the results, but nothing is removed. Right-click a cell → Exclude value to leave it out (it stays on the sheet, struck through); the same menu includes it again.
Files
Open reads a .jgz session, an Excel .xlsx file (each worksheet becomes a tab; formulas give their last computed value) or a .csv / .txt table; you can also drop any of these on the paste bar.
Share
Share (right of the sheet tabs) copies a link that holds every tab, data and settings included. Whoever opens it gets the same sheets and figures; nothing is uploaded, the data travel inside the link. Very large sessions are better sent as a Save file.
Offline
After one visit online, the page works without a network (it keeps itself and its two scripts in the browser).
Export
Export opens the options: this figure or every sheet as one panel figure lettered A, B, C…, PNG or SVG, the on-screen size or a journal column width (8.5 / 11.4 / 17.4 cm), and 300 or 600 dpi (written into the PNG, so Word and Illustrator open it at that size). Copy puts the figure on the clipboard for PowerPoint, Word or a chat.
Theme
The sun / moon button in the ribbon's View group switches between light and dark; 中 / EN switches the interface between Chinese and English (the figure itself stays in English, for papers).
Colours
Besides Claude and Classic Prism, the colour menu offers the journal-style palettes NPG, AAAS, NEJM, Lancet, JAMA, JCO and D3 from ggsci by Nan Xiao (GPL, like plsig).
Privacy
Everything runs in this browser; your data is never uploaded.
Source
Open source on GitHub: report a problem or suggest a feature under Issues.
数据布局
每组一列。配对、重复测量和 Friedman 检验按行匹配（每行一个受试对象）。相关分析以 A 列为 X、B 列为 Y。列联表填计数：列为组，行为结局（由行标题命名）。
双因素
各列是一个因素的水平（如 Control / Drug）；行标题是另一个因素的水平（如 Male / Female）。每个重复单独一行，并重复填写行标题。
分组柱图
要做分组柱状图并在每根柱上标字母（如 Control、P1–P3 × M1–M3），选择分组单元格单因素方差分析。行标题是 x 轴上的分组，每列是一种柱子颜色；每个行标题 × 列的单元格是一组，单元格可以留空（Control 行只填自己那一列）。
排除列
右键一列（或选中多列），选择从分析中排除：数据保留在表格里，但不参与检验和作图。同一菜单可以重新纳入。
表格标签
表格上方的每个标签都有自己的数据、检验、图形设置和撤销记录：一个标签一张图。+（或双击空白处）新建；双击标签重命名；右键可复制、移动或删除。保存会把所有标签写进一个 .jgz 文件，打开会把文件里的标签追加进来。
粘贴
在任意单元格粘贴 Excel 的数据块（⌘/Ctrl V），表格会自动扩展。要替换整张表，点表格下方的粘贴栏（或功能区的粘贴）再按 ⌘/Ctrl V：Excel、Word、网页、PDF 和 CSV 文本都可以，有无表头均可。也可以把 .csv / .txt 文件拖到粘贴栏上。
选择
点一个单元格直接输入即可替换；双击或按 F2 在格内编辑。拖动，或 Shift + 点击 / 方向键选择区域；点行号或列字母选中整行整列；⌘/Ctrl A 全选。点击空白网格会在那里添加行和列。
移动
方向键、Tab 和 Enter 在单元格间移动（在最后一行按 Enter 会新增一行）；⌘/Ctrl + 方向键跳到边缘。
编辑
复制、剪切和粘贴都支持区域；复制一个值粘到一个区域会填满它。Delete 清空区域，⌘/Ctrl D 向下填充，Esc 取消修改。选中区域后输入一个值再按 ⌘/Ctrl Enter，会填入每个单元格。右键可插入 / 删除行和列。拖动列名左侧的点状把手（或右键 → 左移 / 右移）调整列顺序，图跟着变。结果随输入自动更新。
撤销
⌘/Ctrl Z；加 Shift 为重做。撤销同时覆盖数据和图形设置（图表类型、配色、尺寸、样式、检验）。
会话
自动保存在本浏览器中；保存 / 打开（.jgz）可以在不同电脑间转移。
图上文字
点击图上的任意文字即可修改：坐标轴标题、x 轴下的组名或图例。修改组名和图例会同时改表格里的列名或行标题（⌘/Ctrl Z 可撤销）。Enter 确认，Esc 取消。清空的坐标轴标题在屏幕上留一个浅色占位，方便再次点击；导出时不会出现。*** / P = 旁边的关可隐藏图上的字母和星号。
格式
点击柱子可选颜色；点击任意文字（标题、组名、图例、字母 / 星号、y 轴数字）可设置加粗、斜体、颜色和字号。Shift 点击可选中多根柱子；在图上右键可在新标签页比较所选柱子（t 检验、Mann–Whitney、方差分析、Kruskal–Wallis）、只显示或隐藏它们，或把图复制为 SVG / PNG。更精细的编辑，可把 SVG 粘贴到 svguest。
Y 轴
样式 → Y 轴：线性或对数刻度、固定范围（留空为自动）、某个值处的虚线参考线，以及两个值之间的阴影带。
样式
功能区的样式可设置字号、点大小、柱宽、空心或隐藏数据点，以及完整方框或只留左边和底边坐标轴的边框。
我的样式
样式 → 存为我的默认，会在本浏览器保存图表类型、误差线、配色、显著性标记和样式：之后重置、新访问和示例都会使用它。"忘掉它"恢复内置默认。
结果
点击"结果"可折叠所有表格（一句话结论保留），点击某个表格的标题只折叠该表格。折叠状态会被记住。
方法
结果下方有一段可直接复制的论文方法部分文字，描述所做的检验、事后检验、数据表示方式和样本量。
曲线
剂量–反应曲线（4PL）：A 列为剂量，其余列为重复的反应值；以 log10(剂量) 拟合四参数 logistic 模型，给出 EC50 / IC50 及其 95% 置信区间。Kaplan–Meier 生存分析：A 列为时间，其余每列是一组，1 = 事件、0 = 删失（留空 = 不属于该组）；用 log-rank 检验比较生存曲线。
离群值
每列都会做 Grubbs 检验（α = 0.05），可疑离群值在表格中高亮并列在结果里，但不会被删除。右键单元格 → 排除该值即可排除（以删除线保留在表格中），同一菜单可重新纳入。
文件
打开可读取 .jgz 会话、Excel .xlsx 文件（每个工作表成为一个标签；公式取最后一次计算的值）或 .csv / .txt 表格；也可以把这些文件拖到粘贴栏上。
分享
表格标签右侧的"分享"会复制一个包含所有标签（数据和设置）的链接。对方打开后看到相同的表格和图；数据不上传，而是包含在链接里。会话很大时建议用保存的文件发送。
离线
联网访问一次之后，即使没有网络也能使用（页面和两个脚本会保存在浏览器中）。
导出
导出可选：当前图，或把所有表格拼成标好 A、B、C… 的组图；PNG 或 SVG；屏幕尺寸或期刊栏宽（8.5 / 11.4 / 17.4 cm）；300 或 600 dpi（写入 PNG，Word 和 Illustrator 打开即为该尺寸）。复制会把图放到剪贴板，可粘贴到 PowerPoint、Word 或聊天中。
主题与语言
功能区视图组里的太阳 / 月亮按钮切换浅色和深色；"中 / EN"按钮切换界面语言。图本身始终是英文排版，方便投稿。
配色
除 Claude 和 Classic Prism 外，配色菜单还提供来自 ggsci（Nan Xiao 开发，与 plsig 同为 GPL 协议）的期刊风格配色：NPG、AAAS、NEJM、Lancet、JAMA、JCO 和 D3。
隐私
所有计算都在本浏览器中完成，数据不会上传。
源代码
在 GitHub 上开源：可在 Issues 中反馈问题或建议功能。
