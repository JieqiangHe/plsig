Tips

Paste
Paste a block from Excel/Sheets into any cell (⌘/Ctrl V); the grid expands to fit.
Move
Enter / ↑ ↓ move between rows; ← → move between groups at a cell's edge.
Delete
Hover a row number and click × to delete the row; hover a column header and click × to delete the column (group).
Undo
⌘/Ctrl Z; add Shift for redo.
Session
Saved in this browser automatically; Export / Import (.jgz) moves a session between machines.
Export
PNG at 5× the on-screen size (≈ 300 dpi for a 2–3 inch figure); SVG is vector.
Theme
The sun / moon button at the right of the status bar switches between light and dark.
