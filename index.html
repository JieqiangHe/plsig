Tips

Layout
One column per group. Paired, repeated-measures and Friedman tests match values by row (one subject per row). Correlation uses column A as X and B as Y. Contingency tables hold counts: columns are groups, rows are outcomes (named by the row titles).
Two-way
Columns are the levels of one factor (e.g. Control / Drug); the row title names the level of the other (e.g. Male / Female). Put each replicate on its own row and repeat the row title.
Paste
Paste a block from Excel/Sheets into any cell (⌘/Ctrl V); the grid expands to fit. Paste in the ribbon imports TSV / CSV text, optionally with a header row.
Move
Enter / ↑ ↓ move between rows; ← → move between groups at a cell's edge.
Delete
Hover a row number and click × to delete the row; hover a column header and click × to delete the column (group).
Undo
⌘/Ctrl Z; add Shift for redo.
Session
Saved in this browser automatically; Export / Import (.jgz) moves a session between machines.
Export
PNG at 5× the on-screen size (≈ 300 dpi for a 2–3 inch figure); SVG is vector.
Theme
The sun / moon button at the right of the status bar switches between light and dark.
